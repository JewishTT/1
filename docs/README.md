## Event model

`EventEnvelope` is protobuf and versioned: `apps/shared/events/event_envelope.proto`. `EVENT_CATALOG` in `apps/shared/events/topics.py` maps 99 event types onto 29 lanes plus `events.dlq` / `events.quarantine`. Lanes: `acquisition`, `admission`, `cc_temporality`, `claim`, `connector`, `correlation`, `discovery`, `entity-stream`, `evidence`, `feedback`, `frontier`, `governance`, `hypergraph`, `interpretation`, `investigation`, `knowledge`, `observation`, `ontology`, `projection`, `recon`, `resolution`, `review`, `science`, `series`, `statement`, `stream`, `tda`, `temporal-materialization`, `zero_layer`.

Logical time (`observed_at`, `logical_time`) travels inside typed payloads, validated broker-free by `apps/shared/events/timestamps.py`: `produced_at` may never be copied into a payload's `observed_at`.

## Invariants (Constitution)

- **I-1**: Observations are immutable — content-addressed in S3, updates rejected.
- **I-5**: No blob bodies on the bus; raw objects live in storage, events carry refs.
- **I-6**: Identity claims come exclusively from entity resolution; TDA is structural-only.
- **I-11/I-12**: Graph projections are idempotent and rebuildable from stream offsets.
- **Multi-tenant**: Tenant-scoped queries; per-tenant ACLs, indexes and prefixes.

### Blocks "is this thing real?"

| Finding | Evidence |
| --- | --- |
| **The Rust crates have no `fn main` and no `[[bin]]`.** They produce only rlibs; nothing outside their own tests links them. | `apps/acquisition/Cargo.toml`; no `main.rs` anywhere |
| **`worker-browser` (Rust) contains no browser automation** — only an admission gate and a semaphore. The render path is `worker_browser/renderer.py`, whose only implementation is `NoopRenderer`. | `apps/acquisition/worker_browser/renderer.py` |
| **No process consumes `acquisition.request`.** The only `confluent_kafka.Consumer` in the workspace is a hand-rolled one in a proof script. | `apps/interpretation/_consume_searxng.py` |
| **`layer0_pipeline.py` / `acquisition_loop.py` is dead code** — imported only by tests, no HTTP route, no Temporal registration. | `specs/024-.../wave0-verified-state.md` |
