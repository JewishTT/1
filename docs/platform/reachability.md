# Reachability

The import graph says A imports B; that is not the same as *B runs*. This walks the import graph forward from the deployed processes (HTTP app, Temporal worker, acquisition worker, CLI mains) and labels every module by whether production can reach it.

`PRODUCTION` — reachable from a real entrypoint · `TEST_ONLY` — reachable only from tests · `ORPHAN` — imported by nothing (dead or unwired).

|---|---|
| PRODUCTION | 390 |
| TEST_ONLY | 143 |
| ORPHAN | 117 |
| TEST | 321 |
