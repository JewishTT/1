# Architecture Overview

COGNITIVE runs a closed investigation loop. Every hop emits a traceable event; projections are rebuildable; findings resolve to raw evidence.

> Generated by `platform_model/narrative.py` from the tree. Do not edit by hand; run `python -m platform_model.build`. The authoritative machine model is [`../platform/index.md`](../platform/index.md); when the two disagree, the generated model is right.

## Closed loop

```
Investigation → seeds → discovery → frontier → acquisition → Observation (immutable, content-addressed)
    → bus → parse → mentions → candidates → assertions
    → resolution → admission → projections (search/analytics/graph)
    → snapshot → TDA → topological feature → Finding
    → feedback → new acquisition
```

## Key properties (Constitution invariants)

- **I-1**: Observations are immutable — content-addressed in S3, updates rejected.
- **I-5**: No blob bodies on the bus; raw objects live in storage, events carry refs.
- **I-6**: Identity claims come exclusively from entity resolution; TDA is structural-only.
- **I-11/I-12**: Graph projections are idempotent and rebuildable from stream offsets.
- **Multi-tenant**: Tenant-scoped queries; per-tenant ACLs, indexes and prefixes.

## Messaging

Events follow a versioned `EventEnvelope` (protobuf) with `event_id` / `correlation_id` / provenance; idempotent producers dedup on `event_id` / `task_id` / `observation_id`. `EVENT_CATALOG` maps 99 event types onto 29 lanes plus `events.dlq` / `events.quarantine`. Catalog and schemas: `apps/shared/events/`.

## Data plane

| Store | Role |
| --- | --- |
| Object storage (MinIO/S3) | Immutable raw + derived evidence, `s3://knowledge/raw/{tenant}/{ym}/{sha256}`. |
| PostgreSQL 16 | **Authoritative operational state and authoritative relational graph** (ADR-0027). |
| Bus (Redpanda) | Event backbone. "Kafka" names the protocol, never a product (ADR-0026). |
| OpenSearch | Search projection target (ADR-0004). |
| ClickHouse | Observation metrics, source aggregates, cost accounting. |
| Graph serving | Rebuildable **serving** projection only — demoted by ADR-0027. |
| Temporal | Investigation lifecycle + recrawl + temporal materialization. |

The collection fabric's data-plane pieces (content-addressed gate, ETag re-observation, WARC archival/range retrieval, bulk historical replay + backfill, partitioned frontier) are documented in [fabric-collection.md](./fabric-collection.md).
